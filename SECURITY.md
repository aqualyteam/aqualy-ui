# Security reporting

Do not post credentials, customer information or exploit details in public issues. Use GitHub private vulnerability reporting for the public source mirror: [Report a vulnerability](https://github.com/aqualyteam/aqualy-ui/security/advisories/new). This channel was enabled and checked during C0R. It creates a private report for maintainers; do not include customer records or unrelated product credentials.

Supported test baseline: React/React DOM 19.2.1, Node 24.18.0, pnpm 10.24.0 and ESM. Report package/version, affected interaction, minimal synthetic reproduction and impact. No response-time guarantee is promised. Product security, auth and data processing remain owned by the product repositories.
