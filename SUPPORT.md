# Support baseline

Tested: React/React DOM 19.2.1, Next.js 16.0.10, Node 24.18.0, pnpm 10.24.0. Package is ESM with declarations and precompiled scoped CSS; no consumer Tailwind or workspace overrides are required.

Workspace, Professional and Diver; Light/Dark; LTR/RTL; 320/390/1440 are the catalog matrix. Safari/Firefox, real soft keyboards, real devices and screen readers remain NOT RUN pending stable-release acceptance. CJS, React 18 and React Native are not supported promises. Candidate metadata and local verification do not imply registry publication or production readiness.
